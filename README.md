# BM Portfolio

My personal portfolio website, built with **React** and **Vite**.

I'm Beam Chaipotha, a second-year Software Development student (MBO4) at Alfa-college in Groningen. On this website I share who I am, my skills and the projects I have worked on.

## Features

- **Start page**: a 3D glass card that tilts and shines when you move your mouse over it, with a button to enter the portfolio
- **Night sky background**: a dark sky with animated shooting stars, made with plain CSS
- **Home**: an introduction, with a name badge photo that changes from a drawing into a real photo
- **About me**: a short introduction about me, my education and my focus, plus a button to download my CV (PDF)
- **Skills**: the programming languages and frameworks I work with
- **Projects**: project cards with a picture and a description. Each card links to the project on GitHub, and the game can be downloaded as a ZIP file
- **Contact**: an animated glass card that links to my CV, where you can find my contact details
- **Responsive design**: works on computers and phones, with a hamburger menu on small screens
- **Reduced motion**: animations are turned off for visitors who have "reduce motion" switched on

## Built with

- [React](https://react.dev/)
- [Vite](https://vite.dev/)
- [React Icons](https://react-icons.github.io/react-icons/)
- Google Fonts: Baloo 2 and Nunito

## Run it on your own computer

1. Install the packages:

   ```bash
   npm install
   ```

2. Start the website:

   ```bash
   npm run dev
   ```

3. Open the link that appears in the terminal (usually http://localhost:5173).
